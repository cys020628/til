# Android

Kotlin · Android 기술을 하루 단위로 공부하고 정리하는 공간입니다.

## 구성

```
android/
├─ README.md   ← 현재 파일 (진행 현황 + 목차)
└─ TODO.md     ← [1단계] 포맷 실험용 단일 파일
```

포맷이 확정되면 `daily/`(하루 1파일)와 `notes/`(주제별 정리)로 분리합니다.

## 파일명 규칙

- `daily/` : `YYYY-MM-DD-주제.md` (예: `2026-11-24-kotlin-extension-functions.md`)
- `notes/` : `주제.md` — 영문 소문자와 하이픈 (예: `lifecycle-callbacks.md`)
