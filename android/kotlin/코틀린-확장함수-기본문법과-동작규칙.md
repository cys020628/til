# 코틀린 확장 함수: 기본 문법과 동작 규칙 5가지 (Extension Functions)

---

## 1. 기본 문법

`String`에 마지막 글자를 돌려주는 함수 추가

```kotlin
fun String.lastChar(): Char = this[length - 1]

fun main() {
    println("Kotlin".lastChar())   // n
}
```

```
fun String.lastChar(): Char = this[length - 1]
    ①      ②        ③        ④
```

| 번호 | 부분 | 의미 |
|---|---|---|
| ① | `String` | **수신 객체 타입**: 어떤 클래스에 붙일지 |
| ② | `lastChar` | 새로 만드는 함수 이름 |
| ③ | `Char` | 반환 타입 |
| ④ | `this` | **수신 객체**: 점(`.`) 앞의 실제 값 (`"Kotlin"`) |

- `String` 클래스 코드는 건드리지 않고 기능만 추가
- `this`는 생략 가능 (`this[length - 1]` → `get(length - 1)`처럼 `this` 없이 작성 가능)
- 일반 함수처럼 인자와 기본값 사용 가능

```kotlin
fun String.surround(mark: String = "'"): String = "$mark$this$mark"

fun main() {
    println("hi".surround())       // 'hi'
    println("hi".surround("\""))   // "hi"
}
```

## 2. 동작 원리

```kotlin
"Kotlin".lastChar()   // 이렇게 쓴 코드는
lastChar("Kotlin")    // 사실상 이 코드와 같음
```

- 클래스에 함수가 추가되는 것이 아님
- 컴파일하면 **수신 객체를 첫 번째 인자로 받는 정적 함수**로 바뀜
- 점(`.`)으로 부르는 모양만 만들어 주는 문법
- 아래 규칙들의 이유가 모두 여기서 나옴

---

## 3. 규칙 5가지

### 규칙 1. 멤버 함수가 우선

```kotlin
class Person { fun hello() = "멤버 함수" }

fun Person.hello() = "확장 함수"                 // 이름·인자가 같으면 무시됨
fun Person.hello(name: String) = "확장: $name"   // 인자가 다르면 오버로드로 동작

fun main() {
    println(Person().hello())         // 멤버 함수
    println(Person().hello("kim"))    // 확장: kim
}
```

- 원래 있던 함수와 시그니처(이름 + 인자)가 같으면 원래 함수가 호출됨
- 확장 함수로 기존 기능을 덮어쓰는 것은 불가능

### 규칙 2. 호출 함수는 "변수에 적힌 타입"으로 결정

```kotlin
open class Shape
class Rect : Shape()

fun Shape.name() = "Shape"
fun Rect.name() = "Rect"

fun main() {
    val s: Shape = Rect()        // 실제 객체는 Rect, 변수 타입은 Shape
    println(s.name())            // Shape
    println((s as Rect).name())  // Rect
}
```

- 정적 함수라서 **컴파일할 때** 변수 타입 기준으로 정해짐
- 비교: 멤버 함수(오버라이드)는 **실제 객체** 기준으로 호출됨 → 오버라이드 불가

### 규칙 3. nullable 타입에도 붙일 수 있음

```kotlin
fun String?.orDash(): String = if (this.isNullOrEmpty()) "-" else this

fun main() {
    val name: String? = null
    println(name.orDash())      // -
    println("kotlin".orDash())  // kotlin
}
```

- `String?`에 만들면 `null`에도 `.`으로 호출 가능 (일반 멤버는 `name?.length`처럼 `?.` 필요)
- 함수 안에서 `this`가 `null`인 경우를 직접 처리
- 표준 라이브러리의 `isNullOrEmpty()`, `orEmpty()`도 같은 방식

### 규칙 4. 확장 프로퍼티는 get()만 가능

```kotlin
val String.lastIndexSafe: Int
    get() = if (isEmpty()) -1 else length - 1

fun main() {
    println("abc".lastIndexSafe)   // 2
    println("".lastIndexSafe)      // -1
}

// val String.count2: Int = 0   → 컴파일 에러: no backing field
```

- 클래스에 저장 공간(backing field)이 생기지 않아서 초기값 대입 불가
- 계산해서 돌려주는 `get()`만 사용 (`var`이면 `set()`도 직접 구현)

### 규칙 5. 클래스 밖의 확장은 private 접근 불가

```kotlin
class Account {
    private val balance = 100
    val owner = "kim"
}

fun Account.show() {
    println(owner)     // 가능 (public)
    println(balance)   // 컴파일 에러: it is private in 'Account'
}
```

- 확장 함수는 클래스 **바깥**의 함수라서 `public` 멤버만 사용 가능
- `private`, `protected` 멤버는 `public` 함수를 거쳐서 접근

## 4. 만들기 전에 이미 있는지 확인

표준 라이브러리의 자주 쓰는 함수 대부분이 확장 함수

```kotlin
fun main() {
    val nums = listOf(1, 2, 3, 4)
    println(nums.map { it * 2 })                    // [2, 4, 6, 8]
    println(nums.filter { it % 2 == 0 })            // [2, 4]
    println(nums.fold(100) { acc, n -> acc + n })   // 110
    println(nums.joinToString("-"))                 // 1-2-3-4
}
```

Android는 **Android KTX**(`androidx.core:core-ktx`)에도 확장 함수가 많음

| 직접 만들기 쉬운 코드 | KTX에 이미 있는 것 |
|---|---|
| `view.gone()` / `view.visible()` / `visibleIf(조건)` | `view.isGone = true` / `view.isVisible = 조건` |
| `Uri.parse("https://…")` | `"https://…".toUri()` |
| `prefs.edit()` → `putString()` → `apply()` | `prefs.edit { putString("k", "v") }` |
| `getSystemService(X::class.java)` | `context.getSystemService<X>()` |

- `isVisible = false`는 **GONE** 처리
- 직접 만들기 전에 표준 라이브러리와 KTX를 먼저 확인

## 5. Android에서 직접 만드는 예제

```kotlin
// Context 토스트: Activity, Service 등 Context인 곳에서 바로 호출
fun Context.toast(message: String, duration: Int = Toast.LENGTH_SHORT) {
    Toast.makeText(this, message, duration).show()
}

// Fragment용: 위의 Context.toast 재사용
fun Fragment.toast(message: String) = requireContext().toast(message)

// dp → px 변환 (확장 프로퍼티)
val Int.dp: Int
    get() = (this * Resources.getSystem().displayMetrics.density).toInt()

// 이메일 형식 검사
fun String.isValidEmail(): Boolean = Patterns.EMAIL_ADDRESS.matcher(this).matches()
```

```kotlin
// 사용
toast("저장되었습니다")
view.layoutParams.width = 16.dp
"a@b.com".isValidEmail()   // true
"abc".isValidEmail()       // false
```

## 규칙 요약

| 번호 | 규칙 | 핵심 |
|---|---|---|
| 1 | 멤버 함수가 우선 | 인자가 다르면 오버로드로 동작 |
| 2 | 변수에 적힌 타입으로 결정 | 오버라이드 안 됨 |
| 3 | nullable 타입에도 가능 | `this`의 `null` 처리 필요 |
| 4 | 확장 프로퍼티는 `get()`만 | 초기값, backing field 없음 |
| 5 | 클래스 밖에서는 private 접근 불가 | public API만 사용 |

## 주의할 점

- `format`, `get`처럼 흔한 이름은 헷갈리기 쉬우니 피하기
- 프로젝트 전체에서 쓰는 확장은 `ext/` 같은 별도 패키지·파일에 모으기
- 다른 패키지에서 쓰려면 `import` 필요
