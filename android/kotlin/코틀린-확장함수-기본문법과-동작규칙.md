# 코틀린 확장 함수: 기본 문법과 동작 규칙 5가지 (Extension Functions)

---

## 1. 기본 문법

`String`에 마지막 글자를 돌려주는 함수 추가

```kotlin
fun String.lastChar(): Char = this[length - 1]

fun main() {
    println("Kotlin".lastChar())   // n
    println("Android".lastChar())  // d
}
```

```
fun String.lastChar(): Char = this[length - 1]
    ①      ②        ③        ④
```

| 번호 | 부분 | 의미 | 예시에서 |
|---|---|---|---|
| ① | `String` | **수신 객체 타입**: 어떤 클래스에 붙일지 | `String`에 붙임 |
| ② | `lastChar` | 새로 만드는 함수 이름 | `.lastChar()`로 호출 |
| ③ | `Char` | 반환 타입 | 글자 1개를 돌려줌 |
| ④ | `this` | **수신 객체**: 점(`.`) 앞에 있는 실제 값 | `"Kotlin"` |

- `"Kotlin".lastChar()`를 호출하면 `this`에 `"Kotlin"`이 들어감
- `String` 클래스의 코드는 전혀 건드리지 않음
- 직접 못 고치는 클래스(`String`, `List`, `Context`, `View` 등)에 기능을 붙일 때 사용

### this 생략

```kotlin
fun String.lastChar(): Char = this[length - 1]   // this.length 에서 this 생략
fun String.lastChar2(): Char = get(length - 1)   // this.get(...) 에서 this 생략
```

- 클래스 안에서 `this`를 생략하듯 확장 함수 안에서도 생략 가능
- 결과는 동일

### 인자 받기

```kotlin
fun String.repeatWith(sep: String, times: Int): String =
    List(times) { this }.joinToString(sep)

fun main() {
    println("ha".repeatWith("-", 3))   // ha-ha-ha
}
```

- 수신 객체(`this`)는 점 앞에, 일반 인자(`sep`, `times`)는 괄호 안에 작성

### 기본값 인자

```kotlin
fun String.surround(mark: String = "'"): String = "$mark$this$mark"

fun main() {
    println("hi".surround())       // 'hi'
    println("hi".surround("\""))   // "hi"
}
```

- 일반 함수처럼 기본값 인자 사용 가능

### 조금 더 실용적인 예: 긴 문자열 줄이기

```kotlin
fun String.truncate(maxLength: Int): String =
    if (length <= maxLength) this else take(maxLength - 3) + "..."

fun main() {
    println("KotlinFan42".truncate(15))             // KotlinFan42
    println("JetBrainsLoverForever".truncate(15))   // JetBrainsLov...
}
```

- 길이가 `maxLength` 이하면 그대로, 넘으면 앞부분만 잘라서 `...`을 붙임
- `take(n)`은 앞에서 n글자를 가져오는 `String`의 함수

## 2. 동작 원리

```kotlin
// 이렇게 쓴 코드가
"Kotlin".lastChar()

// 사실상 이것과 같은 코드
lastChar("Kotlin")
```

- 컴파일하면 수신 객체를 **첫 번째 인자로 받는 정적 함수**로 바뀜
- `String` 클래스는 변하지 않음 (공식 문서: "확장은 대상 클래스에 새 멤버를 추가하지 않는다")
- 아래 규칙들의 이유가 모두 이 원리에서 나옴

## 3. 규칙 5가지

### 규칙 1. 멤버 함수가 확장 함수보다 우선

```kotlin
class Person {
    fun hello() = "멤버 함수"
}

fun Person.hello() = "확장 함수"

fun main() {
    println(Person().hello())   // 멤버 함수
}
```

- IDE에서 `Extension is shadowed by a member` 경고 표시

#### 인자가 다르면 오버로드로 동작

```kotlin
class Person {
    fun hello() = "멤버 함수"
}

fun Person.hello(name: String) = "확장 함수: $name"

fun main() {
    println(Person().hello())          // 멤버 함수
    println(Person().hello("kim"))     // 확장 함수: kim
}
```

- 이름이 같아도 인자가 다르면 별개의 함수라서 확장 함수가 호출됨
- 기존 클래스에 오버로드 버전을 덧붙이는 용도로 사용 가능

### 규칙 2. 호출 함수는 "변수에 적힌 타입"으로 결정

```kotlin
open class Shape
class Rect : Shape()

fun Shape.name() = "Shape"
fun Rect.name() = "Rect"

fun main() {
    val s: Shape = Rect()        // 실제 객체는 Rect, 변수 타입은 Shape
    println(s.name())            // Shape
    println((s as Rect).name())  // Rect
}
```

- 실제 객체가 `Rect`여도 변수 타입이 `Shape`면 `Shape`용 함수가 호출됨
- 이유: 정적 함수라서 **컴파일할 때** 이미 호출 대상이 정해짐
- `s as Rect`로 타입을 바꿔서 부르면 `Rect`용 함수가 호출됨

#### 멤버 함수(오버라이드)와 비교

```kotlin
open class Animal { open fun sound() = "..." }
class Dog : Animal() { override fun sound() = "멍멍" }

fun main() {
    val a: Animal = Dog()
    println(a.sound())   // 멍멍  (실제 객체 Dog 기준)
}
```

- 멤버 함수(오버라이드)는 **실제 객체** 기준, 확장 함수는 **변수 타입** 기준

### 규칙 3. nullable 타입에도 붙일 수 있음

```kotlin
fun String?.orDash(): String = if (this.isNullOrEmpty()) "-" else this

fun main() {
    val name: String? = null
    println(name.orDash())         // -
    println("kotlin".orDash())     // kotlin
    println("".orDash())           // -
}
```

- 일반 멤버 함수는 `name.length`가 컴파일 에러라서 `name?.length`로 써야 함
- 확장 함수는 `String?`에 만들면 `null`에도 바로 호출 가능
- 함수 안에서 `this`가 `null`인 경우를 직접 처리해야 함
- 표준 라이브러리의 `isNullOrEmpty()`, `orEmpty()`도 같은 방식의 확장 함수

### 규칙 4. 확장 프로퍼티는 get()만 가능

```kotlin
val String.lastIndexSafe: Int
    get() = if (isEmpty()) -1 else length - 1

fun main() {
    println("abc".lastIndexSafe)   // 2
    println("".lastIndexSafe)      // -1
}
```

- 호출할 때 괄호 없이 `"abc".lastIndexSafe`로 사용

#### 초기값을 넣으면?

```kotlin
val String.count2: Int = 0
// 컴파일 에러: Extension property cannot be initialized because it has no backing field
```

- 클래스에 실제 저장 공간(backing field)이 생기지 않아서 값 저장 불가

#### var 확장 프로퍼티는 get + set 모두 구현

```kotlin
var StringBuilder.lastChar: Char
    get() = this[length - 1]
    set(value) { this.setCharAt(length - 1, value) }

fun main() {
    val sb = StringBuilder("Kotlin")
    println(sb.lastChar)   // n
    sb.lastChar = 'N'
    println(sb)            // KotliN
}
```

- 값을 읽고 쓰는 동작을 `get()` / `set()`에서 직접 구현

### 규칙 5. 클래스 밖의 확장은 private, protected 접근 불가

```kotlin
class Account {
    private val balance = 100
    val owner = "kim"
}

fun Account.show() {
    println(owner)     // 가능 (public)
    println(balance)   // 컴파일 에러: Cannot access 'balance': it is private in 'Account'
}
```

- 대신 `public` 함수를 거쳐서는 접근 가능

```kotlin
class User(private val password: String) {
    fun isLoggedIn(): Boolean = true
    fun passwordLength(): Int = password.length
}

fun User.isSecure(): Boolean = passwordLength() >= 8 && isLoggedIn()

fun main() {
    println(User("supersecret").isSecure())   // true
    println(User("abc").isSecure())           // false
}
```

## 4. 직접 만들기 전에: 이미 있는지 먼저 확인

- 공식 문서의 조언: "확장 함수를 만들기 전에 찾는 기능이 표준 라이브러리에 이미 있는지 먼저 확인"

자주 쓰는 함수들이 대부분 확장 함수

```kotlin
fun main() {
    val nums = listOf(1, 2, 3, 4)

    println(nums.map { it * 2 })                       // [2, 4, 6, 8]
    println(nums.filter { it % 2 == 0 })               // [2, 4]
    println(nums.reduce { a, b -> a + b })             // 10
    println(nums.fold(100) { acc, n -> acc + n })      // 110
    println(nums.groupBy { it % 2 == 0 })              // {false=[1, 3], true=[2, 4]}
    println(nums.joinToString("-"))                    // 1-2-3-4
    println(listOf("a", null, "b").filterNotNull())    // [a, b]
    println("  hi  ".trim())                           // hi
}
```

| 호출 | 선언된 모양 (단순화) |
|---|---|
| `nums.map { }` | `fun <T, R> Iterable<T>.map(transform: (T) -> R): List<R>` |
| `nums.filter { }` | `fun <T> Iterable<T>.filter(predicate: (T) -> Boolean): List<T>` |
| `"  hi  ".trim()` | `fun String.trim(): String` |
| `x.let { }` | `fun <T, R> T.let(block: (T) -> R): R` |

- `List`에는 `map`, `filter`가 멤버로 들어 있지 않고 확장 함수로 붙어 있음
- 이후 공부할 스코프 함수 `let`, `apply`, `run`, `also`도 모두 확장 함수
- Android에서는 표준 라이브러리 말고 **Android KTX**에도 확장 함수가 많음 → 9번 참고

## 5. 여러 종류의 타입에 붙이기

### 인터페이스에 붙이기

```kotlin
interface User {
    val name: String
    val email: String
}

fun User.displayInfo(): String = "User(name=$name, email=$email)"

class RegularUser(override val name: String, override val email: String) : User

fun main() {
    val user = RegularUser("Alice", "alice@example.com")
    println(user.displayInfo())   // User(name=Alice, email=alice@example.com)
}
```

- 인터페이스에 한 번만 만들면 그 인터페이스를 구현한 **모든 클래스**에서 사용 가능

### Map에 붙이기

```kotlin
fun Map<String, Int>.mostVoted(): String? =
    maxByOrNull { (_, value) -> value }?.key

fun main() {
    val poll = mapOf("Cats" to 37, "Dogs" to 58, "Birds" to 22)
    println(poll.mostVoted())              // Dogs
    println(emptyMap<String, Int>().mostVoted())   // null
}
```

- 가장 큰 값을 가진 항목의 키를 반환, 비어 있으면 `null`
- `?.key`로 `null`일 때는 키를 꺼내지 않고 `null` 그대로 반환

### 제네릭: 어떤 타입의 리스트든 붙이기

```kotlin
fun <T> List<T>.secondOrNull(): T? = if (size >= 2) this[1] else null

fun main() {
    println(listOf(10, 20, 30).secondOrNull())   // 20
    println(listOf("a").secondOrNull())          // null
    println(emptyList<Int>().secondOrNull())     // null
}
```

- `<T>`는 함수 이름 **앞**에 선언 (`fun <T> List<T>.…`)
- 반환 타입 `T?` → 요소가 부족하면 `null`

#### 조건을 건 제네릭

```kotlin
fun <T : Comparable<T>> List<T>.isSortedAsc(): Boolean =
    zipWithNext().all { (a, b) -> a <= b }

fun main() {
    println(listOf(1, 2, 3).isSortedAsc())   // true
    println(listOf(3, 1, 2).isSortedAsc())   // false
}
```

- `T : Comparable<T>` → 크기 비교가 가능한 타입만 허용

## 6. 응용 문법

### infix: 점과 괄호 없이 호출

```kotlin
infix fun Int.pow(exp: Int): Int {
    var result = 1
    repeat(exp) { result *= this }
    return result
}

fun main() {
    println(2 pow 10)     // 1024
    println(2.pow(10))    // 1024 (일반 호출도 가능)
}
```

- `infix`를 붙이면 `a pow b`처럼 영어 문장처럼 호출 가능
- 조건: 수신 객체가 있고 인자가 **정확히 1개**인 함수만 가능
- 표준 라이브러리의 `1 to "one"`(`to`)도 같은 방식

### operator: 연산자 사용

```kotlin
operator fun String.times(n: Int): String = this.repeat(n)

fun main() {
    println("ab" * 3)   // ababab
}
```

- 이름이 약속된 함수(`plus`, `minus`, `times`, `get` 등)에 `operator`를 붙이면 `+`, `-`, `*`, `[]` 사용 가능

### 수신 객체가 있는 함수 타입 (람다 버전)

```kotlin
val isInRange: Int.(min: Int, max: Int) -> Boolean = { min, max -> this in min..max }

fun main() {
    println(5.isInRange(1, 10))    // true
    println(20.isInRange(1, 10))   // false
}
```

- `Int.(min: Int, max: Int) -> Boolean` → "`Int`를 수신 객체로 받고 `min`, `max`를 인자로 받아 `Boolean`을 돌려주는 함수" 타입
- 람다 안에서 `this`가 수신 객체 (`5.isInRange(...)`면 `this`는 5)
- 이후 공부할 `apply { }`, `with(x) { }`, `buildString { }`이 이 구조를 사용

### 이름 없는 확장 함수 (익명 확장 함수)

```kotlin
data class Order(val weight: Double)

fun main() {
    val calculateShipping = fun Order.(rate: Double): Double = this.weight * rate

    val order = Order(2.5)
    println(order.calculateShipping(3.0))   // 7.5
}
```

- 이름을 전역에 남기고 싶지 않을 때, 한 곳에서만 쓸 때 사용
- 함수 모양만 `fun 수신객체타입.(인자)`로 작성

### companion object 확장

```kotlin
class User(val name: String) {
    companion object
}

fun User.Companion.guest() = User("guest")

fun main() {
    println(User.guest().name)   // guest
}
```

- 클래스 이름으로 직접 호출하는 정적 함수처럼 보이게 추가 가능
- 조건: 대상 클래스에 `companion object`가 선언되어 있어야 함 (내용이 비어 있어도 됨)

## 7. 멤버 확장 함수

```kotlin
class Host(val hostname: String) {
    fun printHostname() { print(hostname) }
}

class Connection(val host: Host, val port: Int) {
    fun printPort() { print(port) }

    // Host에 붙이는 확장 함수. Connection 안에서만 사용 가능
    fun Host.printConnectionString() {
        printHostname()   // Host의 함수
        print(":")
        printPort()       // Connection의 함수
    }

    fun connect() {
        host.printConnectionString()
    }
}

fun main() {
    Connection(Host("kotl.in"), 443).connect()   // kotl.in:443
    // Host("kotl.in").printConnectionString()   // 컴파일 에러: Unresolved reference
}
```

- 수신자가 **둘**이라서 둘의 멤버를 모두 이름만으로 호출 가능

| 이름 | 누구 | 예시에서 |
|---|---|---|
| 확장 수신자 (extension receiver) | 확장 대상 타입 | `Host` |
| 디스패치 수신자 (dispatch receiver) | 확장 함수를 선언한 클래스 | `Connection` |

- 둘에 같은 이름의 멤버가 있으면 **확장 수신자**가 우선
- 디스패치 수신자를 가리킬 때는 `this@Connection`처럼 클래스 이름을 붙여서 작성
- 사용 범위를 선언한 클래스 안으로 좁히고 싶을 때 사용

## 8. 선언 위치, 공개 범위, 자바 호출

### 선언 위치와 import

```kotlin
// 파일: com/example/ext/StringExt.kt
package com.example.ext

fun String.lastChar(): Char = this[length - 1]
```

```kotlin
// 다른 파일에서 사용
import com.example.ext.lastChar

fun main() {
    println("Kotlin".lastChar())   // n
}
```

- 보통 파일 최상위(클래스 밖)에 선언
- 다른 패키지에서 쓰려면 `import` 필요
- 이름이 같은 확장이 여러 패키지에 있으면 `import`한 쪽이 호출됨

### 공개 범위 (visibility)

```kotlin
// 파일: StringUtils.kt
private fun removeWhitespace(input: String): String =
    input.replace("\\s".toRegex(), "")

fun String.cleaned(): String = removeWhitespace(this)   // 같은 파일의 private 함수 사용 가능

internal fun String.parseJson(): Map<String, Any> = mapOf("key" to "value")
```

| 키워드 | 사용 가능 범위 |
|---|---|
| (없음, public) | 어디서나 |
| `internal` | 같은 모듈 안에서만 |
| `private` | 같은 파일 안에서만 |

- 확장 함수도 일반 함수와 같은 공개 범위 규칙 적용
- 같은 파일의 `private` 최상위 함수는 확장 함수 안에서 사용 가능 (규칙 5의 제한은 "수신 객체 클래스의 private 멤버")

### 자바에서 호출

```kotlin
// 파일: StringExt.kt
fun String.lastChar(): Char = this[length - 1]
```

```java
// 자바 코드
char c = StringExtKt.lastChar("Kotlin");   // 파일명 + Kt 클래스의 정적 메서드
```

```kotlin
// 이름을 바꾸고 싶을 때: 파일 맨 위에 선언
@file:JvmName("StringUtils")
```

```java
char c = StringUtils.lastChar("Kotlin");
```

- 자바에는 확장 함수 문법이 없어서 `파일명Kt.함수(수신 객체, 인자…)` 형태로 호출
- 2번의 "정적 함수로 바뀐다"를 눈으로 확인할 수 있는 부분

## 9. Android에서 활용

### 직접 만드는 예제

#### Context 토스트

```kotlin
fun Context.toast(message: String, duration: Int = Toast.LENGTH_SHORT) {
    Toast.makeText(this, message, duration).show()
}

// Activity 안에서
toast("저장되었습니다")
```

- `Activity`는 `Context`를 상속하므로 `toast(...)`를 바로 호출 가능
- `Toast.makeText(this, ..., ...).show()` 반복 작성이 사라짐

#### Fragment에서도 토스트

```kotlin
fun Fragment.toast(message: String) = requireContext().toast(message)

// Fragment 안에서
toast("불러오기 실패")
```

- 위에서 만든 `Context.toast()`를 다른 확장 함수에서 재사용

#### View 보이기 / 숨기기

```kotlin
fun View.visible() { visibility = View.VISIBLE }
fun View.gone() { visibility = View.GONE }
fun View.invisible() { visibility = View.INVISIBLE }

// 사용
binding.progressBar.gone()
binding.resultText.visible()
```

- `TextView`, `Button`, `ProgressBar` 등 모든 `View` 자식 클래스에서 사용 가능
- 연습용으로 좋지만 KTX에 같은 기능이 있음 → 아래 KTX 참고

#### dp를 px로 변환

```kotlin
val Int.dp: Int
    get() = (this * Resources.getSystem().displayMetrics.density).toInt()

// 사용
view.layoutParams.width = 16.dp
```

- 숫자 뒤에 `.dp`를 붙이는 확장 프로퍼티

#### 이메일 형식 검사

```kotlin
fun String.isValidEmail(): Boolean = Patterns.EMAIL_ADDRESS.matcher(this).matches()

// 사용
"a@b.com".isValidEmail()   // true

```

#### 시간(Long)을 날짜 문자열로

```kotlin
fun Long.toDateString(pattern: String = "yyyy-MM-dd"): String =
    SimpleDateFormat(pattern, Locale.getDefault()).format(Date(this))

// 사용
System.currentTimeMillis().toDateString()              // 예: 2026-11-24
System.currentTimeMillis().toDateString("MM/dd HH:mm") // 예: 11/24 09:30
```

- 기본값 인자를 같이 사용해서 패턴을 생략하면 기본 형식으로 변환

### Android KTX: 이미 만들어져 있는 확장 함수

- Android KTX(`androidx.core:core-ktx`)는 Android API에 코틀린용 확장 함수를 붙여 놓은 라이브러리

| 직접 만든 코드 | KTX에 이미 있는 것 |
|---|---|
| `view.gone()` / `view.visible()` | `view.isGone = true` / `view.isVisible = true` |
| `visibleIf(조건)` 같은 함수 | `view.isVisible = 조건` (`false`면 GONE) |
| `Uri.parse("https://…")` | `"https://…".toUri()` |
| `edit()` → `putString()` → `apply()` | `prefs.edit { putString("k", "v") }` |
| `getSystemService(X::class.java)` | `context.getSystemService<X>()` |
| 레이아웃이 그려진 뒤 실행하는 리스너 | `view.doOnLayout { … }` |

```kotlin
import androidx.core.view.isVisible
import androidx.core.net.toUri
import androidx.core.content.edit

binding.progressBar.isVisible = false   // GONE 처리
val uri = "https://developer.android.com".toUri()
prefs.edit { putString("name", "kim") }   // apply()까지 자동 호출
```

- 위 함수들은 모두 `View.isVisible`, `String.toUri()`, `SharedPreferences.edit {}`처럼 **확장 함수/프로퍼티**로 만들어져 있음
- 직접 만들기 전에 KTX와 표준 라이브러리에 있는지 먼저 확인
- 새 프로젝트에는 `core-ktx`가 기본으로 들어 있는 경우가 많음 (`build.gradle`에서 확인)

## 규칙 요약

| 번호 | 규칙 | 핵심 |
|---|---|---|
| 1 | 멤버 함수가 확장 함수보다 우선 | 인자가 다르면 오버로드로 동작 |
| 2 | 호출 함수는 변수에 적힌 타입으로 결정 | 오버라이드(다형성) 안 됨 |
| 3 | nullable 타입에도 붙일 수 있음 | `this`의 `null` 처리 필요 |
| 4 | 확장 프로퍼티는 `get()`/`set()`만 가능 | 초기값, backing field 없음 |
| 5 | 클래스 밖의 확장은 private, protected 접근 불가 | public API만 사용 |

## 주의할 점

- `format`, `get`처럼 흔한 이름은 다른 함수와 헷갈릴 수 있어서 피하기
- 같은 이름의 확장이 여러 곳에 있으면 `import`에 따라 다른 함수가 호출될 수 있음
- 프로젝트 전체에서 쓰는 확장은 `ext/` 같은 별도 패키지·파일에 모으기
- 한 곳에서만 쓰는 확장은 `private`, 멤버 확장, 익명 확장으로 범위를 좁히기
- 만들기 전에 표준 라이브러리와 Android KTX에 이미 있는지 먼저 확인

## 용어

| 용어 | 뜻 |
|---|---|
| 수신 객체 (receiver) | 점(`.`) 앞에 오는 값. 함수 안에서 `this`로 접근 |
| 수신 객체 타입 | 함수 이름 앞에 적는 타입 (`String.lastChar`의 `String`) |
| 정적 디스패치 | 어떤 함수를 부를지 컴파일 시점에 정하는 방식 |
| 동적 디스패치 | 어떤 함수를 부를지 실행 시점의 실제 객체로 정하는 방식 (오버라이드) |
| 멤버 함수 | 클래스 안에 원래 정의된 함수 |
| 멤버 확장 함수 | 다른 클래스 안에서 선언한 확장 함수 |
| 확장 수신자 / 디스패치 수신자 | 멤버 확장 함수의 두 수신자 (확장 대상 타입 / 선언한 클래스) |
| KTX | Android API에 코틀린용 확장 함수를 붙여 놓은 라이브러리 (`core-ktx` 등) |
