## 1. 인터페이스에 붙이기

```kotlin
interface User {
    val name: String
    val email: String
}

fun User.displayInfo() = "User(name=$name, email=$email)"

class RegularUser(override val name: String, override val email: String) : User

fun main() {
    println(RegularUser("Alice", "a@x.com").displayInfo())   // User(name=Alice, email=a@x.com)
}
```

- 인터페이스에 한 번만 만들면 그 인터페이스를 구현한 **모든 클래스**에서 사용 가능

## 2. 제네릭 확장 함수

```kotlin
fun <T> List<T>.secondOrNull(): T? = if (size >= 2) this[1] else null

fun main() {
    println(listOf(10, 20, 30).secondOrNull())   // 20
    println(listOf("a").secondOrNull())          // null
}
```

- `<T>`는 함수 이름 **앞**에 선언 (`fun <T> List<T>.…`)
- 타입 조건이 필요하면 `<T : Comparable<T>>`처럼 제한 가능

## 3. infix, operator

```kotlin
infix fun Int.pow(exp: Int): Int {
    var result = 1
    repeat(exp) { result *= this }
    return result
}

operator fun String.times(n: Int): String = this.repeat(n)

fun main() {
    println(2 pow 10)   // 1024
    println("ab" * 3)   // ababab
}
```

- `infix`: 수신 객체가 있고 인자가 **정확히 1개**인 함수에 사용 → 점과 괄호 없이 `a pow b`
- `operator`: 약속된 이름(`plus`, `minus`, `times`, `get` 등)에 붙이면 `+`, `-`, `*`, `[]` 사용 가능

## 4. 수신 객체가 있는 함수 타입, 익명 확장 함수

```kotlin
// 람다 버전: this가 Int
val isInRange: Int.(min: Int, max: Int) -> Boolean = { min, max -> this in min..max }

// 익명 함수 버전
data class Order(val weight: Double)
val calculateShipping = fun Order.(rate: Double): Double = this.weight * rate

fun main() {
    println(5.isInRange(1, 10))                 // true
    println(20.isInRange(1, 10))                // false
    println(Order(2.5).calculateShipping(3.0))  // 7.5
}
```

- `Int.(…) -> Boolean` → "`Int`를 수신 객체로 받는 함수" 타입
- 이름을 전역에 남기고 싶지 않거나 한 곳에서만 쓸 때 사용
- `apply { }`, `run { }`, `buildString { }`이 이 구조 → [스코프 함수 노트](코틀린-스코프함수-let-apply-run-also-with-비교.md)

## 5. companion object 확장

```kotlin
class User(val name: String) {
    companion object          // 내용이 비어 있어도 선언 필요
}

fun User.Companion.guest() = User("guest")

fun main() {
    println(User.guest().name)   // guest
}
```

- 클래스 이름으로 바로 호출하는 정적 함수처럼 추가 가능

## 6. 멤버 확장 함수

다른 클래스 **안에서** 만든 확장 함수. 그 클래스 안에서만 사용 가능

```kotlin
class Host(val hostname: String) {
    fun printHostname() { print(hostname) }
}

class Connection(val host: Host, val port: Int) {
    fun printPort() { print(port) }

    fun Host.printConnectionString() {   // Host 확장, Connection 안에서만 사용 가능
        printHostname()                  // Host의 함수
        print(":")
        printPort()                      // Connection의 함수
    }

    fun connect() { host.printConnectionString() }
}

fun main() {
    Connection(Host("kotl.in"), 443).connect()   // kotl.in:443
    // Host("kotl.in").printConnectionString()   // 컴파일 에러: unresolved reference 'printConnectionString'
}
```

| 이름 | 누구 | 예시에서 |
|---|---|---|
| 확장 수신자 | 확장 대상 타입 | `Host` |
| 디스패치 수신자 | 확장을 선언한 클래스 | `Connection` |

- 같은 이름의 멤버가 둘 다 있으면 **확장 수신자** 우선
- 디스패치 수신자는 `this@Connection`으로 명시

## 7. 선언 위치와 공개 범위

```kotlin
// 파일: com/example/ext/StringExt.kt
package com.example.ext

private fun removeWhitespace(s: String) = s.replace("\\s".toRegex(), "")

fun String.cleaned(): String = removeWhitespace(this)   // 같은 파일의 private 함수는 사용 가능
internal fun String.parseJson(): Map<String, Any> = mapOf("k" to "v")
```

```kotlin
// 다른 패키지에서 사용
import com.example.ext.cleaned
```

| 키워드 | 사용 가능 범위 |
|---|---|
| (없음, public) | 어디서나 (다른 패키지는 `import` 필요) |
| `internal` | 같은 모듈 안 |
| `private` | 같은 파일 안 |

## 8. 자바에서 호출

```kotlin
// 파일: StringExt.kt
fun String.lastChar(): Char = this[length - 1]
```

```java
// 자바 코드: 파일명 + Kt 클래스의 정적 메서드
char c = StringExtKt.lastChar("Kotlin");   // n
```

```kotlin
// 파일 맨 위에 @file:JvmName("StringUtils")를 쓰면
@file:JvmName("StringUtils")
```

```java
char c = StringUtils.lastChar("Kotlin");   // n
```

- 자바에는 확장 함수 문법이 없어서 `파일명Kt.함수(수신 객체, 인자…)` 형태
- 기본편 2번의 "정적 함수로 바뀐다"를 확인할 수 있는 부분
- 검증: Kotlin 2.4.21과 Java 21에서 두 방식 모두 호출해 `n` 출력 확인
